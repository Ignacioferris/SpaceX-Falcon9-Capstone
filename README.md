# SpaceX Falcon 9 Landing Prediction

This project was completed as part of the IBM Data Science Professional Certificate.

The goal was to analyze SpaceX Falcon 9 launch data and predict whether the first stage would land successfully.

The project includes:

- Data collection using the SpaceX API
- Web scraping
- Data cleaning and preparation
- Exploratory data analysis
- SQL analysis
- Folium maps
- Plotly Dash dashboard
- Machine learning classification

## Main Results

The dataset contains 90 Falcon 9 launches, with an overall landing success rate of about 66.7%.

Four classification models were tested:

- Logistic Regression
- SVM
- Decision Tree
- KNN

All four models achieved about 83.3% accuracy on the test set.

## Tools Used

Python, Pandas, Matplotlib, Seaborn, SQL, BeautifulSoup, Folium, Plotly Dash and Scikit-learn.
