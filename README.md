# SpaceX Falcon 9 First Stage Landing Prediction

IBM Data Science Professional Certificate - Applied Data Science Capstone Project.

This repository contains the notebooks and datasets used to analyze Falcon 9 launches and predict whether the first stage will land successfully.

## Contents

- Data collection using SpaceX API
- Web scraping
- Data wrangling
- Exploratory data analysis
- SQL analysis
- Folium interactive maps
- Plotly Dash dashboard
- Machine learning classification
